  - **解决**：string 比较的是字典序，不是数值大小。
string a = "2";
string b = "10";
if (a < b) {
    cout << "a smaller";
}
结果会是 a > b，因为字符串是逐字符比较：
"2"
"10"

字符 '2' > '1'，所以 "2" > "10"。
