- 注意区别
git merge main：在 testing 分支上执行，把 main 合并进 testing，main 不变。
git merge testing：在 main 分支上执行，把 testing 合并进 main，testing 不变。
所以你现在在 testing 分支执行 git merge main，你的 main 还有，而且完全不受影响。
