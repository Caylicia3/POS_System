## 今日学到的命令
- 
pwd：我在哪？（显示当前目录的绝对路径）
ls：这里有啥？（列出当前目录下的文件） 
cd：我要去哪？（切换目录，比如 cd POS_System）

- `pwd` :不是 Git 的命令，而是一个 Shell（终端）命令。Print Working Directory（打印工作目录）的缩写。
作用：
在终端里，你经常会 cd（切换目录），切来切去很容易忘记自己当前到底在哪个文件夹里。输入 pwd 并回车，它就会告诉你你当前所在的绝对路径。

-  `ls` :List（列表）的缩写。它的作用是列出当前目录下的所有文件和文件夹。
  - `ls -l` （长格式显示，Long）
    不仅列出名字，还会显示文件的权限、所有者、文件大小、修改时间等详细信息。
  - `ls -a` （显示所有文件，All）在 Linux 和 Git 中，以 . 开头的文件是隐藏文件（比  如 .git, .gitignore）。直接敲 ls 是看不见它们的。加上 -a 就能把它们全部显示出来。
  - `ls -la` （组合技，最常用）
    把上面两个结合起来，既显示隐藏文件，又显示详细信息。这是很多程序员最常敲的命令之一。
  - `ls -lh` ：和 `-l` 类似，但文件大小会显示为 KB、MB 等人类能看懂的格式（h = human-readable）。

  - `ls -R` ：递归列出，不仅列出当前目录，还会列出所有子文件夹里的内容。
